# 小曼测试日志管理页面

本目录只包含公开网页。后台接口及私有日志保存在腾讯云，管理员密码不在本仓库。

在GitHub新建公开仓库 `xiaoman-logs`，上传本目录的文件（不要上传外层ZIP或整个内部工具目录）。
然后打开 Settings → Pages → Deploy from a branch → main → /(root) → Save。
等待发布完成后，使用Pages页面的 Visit site 打开，不要双击本地HTML。

本机持续记录，日志自动每12小时上传；网页“采集一次”成功后，下次自动时间从完成时重新等12小时。需要配套v2.2.2电脑端。

页面已配置现有腾讯云接口。需要先把配套的v1.1.0云函数代码包上传到原日志函数，保留原有环境变量和运行角色。
支持的页面来源：`https://zhanglucker-sketch.github.io`、`https://lucker.zhangqi.art`。
无需在本仓库配置CNAME，也不需要申请新域名和证书。

源码中只放公开接口地址。不要上传设备接入文件、私密部署参数、密码、会话令牌或导出的日志。
